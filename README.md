## 📖 About

AutoRestartProxy is a high-performance Minecraft proxy plugin built with **Java 21** for the **Velocity** proxy platform. It streamlines network maintenance by allowing administrators to trigger a timed network restart using a single command. The plugin ensures players are kept informed in real-time and disconnects them safely before the proxy shuts down, preventing data desynchronization.

---

## ✨ Features

- ⏳ **Live Countdown**: Displays the remaining time before the restart dynamically in chat, as well as on-screen via **Titles** and **Subtitles**.
- 🔐 **Safe Disconnection**: Automatically kicks all active players safely right before the restart sequence executing, reducing the risk of player data loss.
- ⚡ **Plug & Play**: Zero complex setup required – just drop the jar into your plugins directory and you are good to go.
